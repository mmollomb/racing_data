\# racing\_data experiments



This folder contains standalone experiments for understanding the predictive-punter/racing\_data package.



Confirmed:

\- Package installs in editable mode on Windows

\- Core classes import successfully

\- Runner.carrying works

\- Runner.actual\_weight works

\- Runner.actual\_distance works when Race is linked through property\_cache

\- Horse.performances works when PerformanceList is linked through property\_cache

\- Runner form features work when Meet, Race, Runner, Horse, and Performance objects are manually linked



Confirmed features:

\- career starts/wins/places

\- win\_pct/place\_pct

\- last\_10

\- last\_12\_months

\- at\_distance

\- on\_track

\- on\_good/on\_soft

\- with\_jockey

\- spell

\- up

\- earnings

\- ROI

\- momentum



Note:

This is a separate research repo. It is not connected to any PDF downloader project.
